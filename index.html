How to connect

1. Plug the OBDLink CX into the OBD port under the dash, driver's side, above the pedals.
2. Turn ignition on (or start the engine).
3. Open this page in a browser with Web Bluetooth: Chrome or Edge on Android, Mac, Windows or ChromeOS. On iPhone/iPad, Safari can't do this; use the Bluefy browser app.
4. Tap Connect and pick the device named OBDLink CX. Don't pair it in phone Bluetooth settings first.
5. Close the OBDLink / BimmerCode apps — only one app can talk to the adapter at a time.
