# BMW OBD Dashboard

Web Bluetooth OBD-II dashboard for a 2015 BMW X4 xDrive35i (F26 / N55), also works with any CAN OBD-II car.
Live gauges, fault codes, and trip recording stored locally in the browser.

Open https://snacks-rams-1m.github.io/bmw-obd-dashboard/ in Chrome (Android/desktop) or Bluefy (iPhone) with a BLE ELM327 adapter (e.g. Veepeak OBDCheck BLE+).
